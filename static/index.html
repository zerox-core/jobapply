为什么我在自己浏览器里打开还是未登录？

系统用的是独立自动化浏览器，登录态保存在它专属的 browser_profile 目录——和你日常浏览器是两套、互不相通（有意隔离，不动你日常浏览器的数据）。所以正确姿势是一切操作都从这里进：在下方「打开去登录」登录一次，之后职位库 / 任务里的链接都点「打开」，系统会在自动化浏览器里打开并自动带上登录态。
进阶：也可以让系统直接接管你日常的 Chrome / Edge（config.yaml 里配 cdp_endpoint，步骤见该文件注释），那样连这一次登录都省掉。

登录态管理（浏览器 Cookie 持久化保存）

常用：
点「打开去登录」会弹出浏览器窗口：用微信 / QQ / 手机号等方式扫码或登录一次，登录态会自动保存在本机 browser_profile 里——之后所有投递、填表都复用这份登录状态，不需要每次重登。登录完成后直接关掉浏览器或点「忘记」以外的操作即可，状态已存好。
